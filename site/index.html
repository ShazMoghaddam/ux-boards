ux-boards · examples

UX documentation from one YAML file

Information architecture, navigation by screen size, wireframes and a visual system with contrast checks, rendered as boards you can share or print. Both products below are fictional.

Make your own

git clone https://github.com/ShazMoghaddam/ux-boards.git && cd ux-boards
pip install -r requirements.txt
python generator/generate.py init projects/my-product
python generator/generate.py build projects/my-product/spec.yaml -o projects/my-product/out
